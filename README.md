# Todo List Uygulaması

HTML, CSS ve JavaScript kullanılarak geliştirilmiş, günlük görevlerinizi takip etmenizi sağlayan basit ve dinamik bir Yapılacaklar Listesi (Todo List) uygulaması.

## 🚀 Özellikler

* Yeni görev ekleme ve silme
* Tamamlanan görevleri işaretleme
* Şık ve kullanıcı dostu arayüz
* Duyarlı (responsive) tasarım

## 📁 Proje Yapısı

```text
busra-todo-app/
├── index.html   # Ana HTML yapısı
